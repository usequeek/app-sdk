# Security policy

## Report a vulnerability

Email <security@queek.com.ng> with what you found, how to reproduce it, and the
impact you see. Please do not open a public issue, discussion or pull request
for a vulnerability, so that it can be fixed before it is disclosed.

We acknowledge every report and keep you updated while we investigate and fix
it. We follow coordinated disclosure: please give us a reasonable window to ship
a fix before you share details publicly. We credit reporters in the release
notes unless you prefer to stay anonymous.

## Scope

This policy covers the code in this repository, published as `@usequeek/app-sdk`: signed install and webhook handlers, installation tokens and the encrypted installation store.

If you find a Queek key or secret in this repository, report it the same way
and do not use it.

## Supported versions

We fix security issues in the latest release. If you are on an older version,
upgrade first and check whether the issue still reproduces.
